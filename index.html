就活では、企業ごとのマイページ・説明会・選考予定・ES下書きが急速に増え、メール / カレンダー / メモが分散しがちです。本ツールは、これらをJSON を単一の真実とした構造化データとして保持し、ブラウザ上で一元的に閲覧・編集できるダッシュボードとして実装しました。

最大の特徴は、Anthropic の Claude Code と Gmail MCP（Model Context Protocol）を連携させ、新着メールから企業マイページ・説明会・インターン情報・ES 設問を自動抽出して JSON に書き込む点。自然言語の指示「Gmail同期して」だけで メール解析 → 構造化 → 重複排除 → ビュー更新 までが完結します。

設計思想: AI エージェントを単なるチャットボットではなく、データパイプラインの一部として組み込んだ実装。スキーマ定義・重複排除キー・パスワード分離管理など、運用に耐える仕様まで詰めています。

03 Architecture

AI エージェントをデータパイプラインに組み込む構成

データフロー:

Gmail （受信箱）
  ↓ Gmail MCP（スレッド検索 / 取得）
Claude Code（自然言語指示で起動）
  ↓ 抽出 / 重複排除（source_thread_id 照合）
JSON（mypages / events / internships / es / companies）
  ↓ sync.py（JSON → data.js 再生成）
dashboard.html（Vanilla JS で描画）

主要な設計判断:

  • JSON を単一の真実 ─ DB を持たず、人間が直接編集できる構造化ファイルだけで運用
  • スキーマ駆動 ─ 各 JSON のスキーマを CLAUDE.md に明文化し、AI が常に同じ形式で書き込むよう制約
  • 重複排除キー ─ Gmail の thread_id を保持し、再同期時の重複追加を防止
  • 機密分離 ─ パスワードは secrets.json に隔離（gitignore）し、本体 JSON からは参照キーのみで指す
  • ステータスは更新、削除はしない ─ ES や選考の履歴がトレース可能
